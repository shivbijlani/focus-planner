# Roadmap

This page records **known gaps and forward direction** from the **200 open issues** in the planner repository. The system described in the other pages is not finished: every item below is a defect, an unbuilt mechanism, or a decided direction that the current code does not yet satisfy. Issues with a `priority:` label are grouped by it; the rest are grouped by label, then by theme. Closed issues are named in words elsewhere in the spec, never listed here. Read alongside [Behaviour](Behaviour), [Reliability](Reliability), [Prioritisation](Prioritisation) and the relevant `Domain-*` page.

## Critical

8 open issues carry `priority: critical`. These are the gaps that let the unattended agent misbehave silently or stop altogether: agent-declared completion being treated as user closure, Google Doc comments that cannot be attributed to a person, a hung run freezing the whole half-hourly schedule, and browser slots that watchdogs cannot recover when merely stuck.
